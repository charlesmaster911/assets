## 0. 한 줄 결론

이 매뉴얼의 1~18장(구매대행 입문·첫 주문)은 쥬얼아이스가 **이미 통과한 구간**이라 버린다.
쓸 것은 **19~34장(수입 전환·총판·OEM·운영)과 37~40장(양식·중단 기준)** 이며,
그중 지금 당장 구멍인 것은 **① SKU별 공헌이익 ② 금형·권리 소유 ③ 식품용 기구 적합성 문서 ④ 13주 현금표** 네 가지다.

## 2. 즉시 적용 (0~2주) — 매뉴얼이 지적한 현재 구멍

### 2-1. SKU별 공헌이익 원장 (매뉴얼 10장 + 양식 09)
매뉴얼의 핵심 경고: **마진율이 아니라 공헌이익**, 그리고 **할인 10%가 공헌이익 51%를 지운다**.

듀오메이커 1개 기준 계산틀 (숫자는 전부 `[가정]`, 실제 정산서로 교체):

|---|---|
| 소비자가(VAT 포함) | `[가정]` |

| 도착원가 (제품+몰드분담+국제운송+관세+입고) | |
| 플랫폼·결제 수수료 | |

→ 산출물: `JI_손익_SKU별공헌이익_2026Q3.xlsx`
→ 판정 기준: **월 고정비 ÷ 공헌이익 = 손익분기 수량**을 SKU별로 명시. 이 숫자 없이 광고 증액 금지.

### 2-2. 광고를 "노출"이 아니라 "공헌이익"으로 판정 (15장)
현재 유튜브 하이라이트 광고(duo_yt4 / ablr_yt4)가 운영 중이다. 매뉴얼 공식을 그대로 적용:

```
목표 CAC = 주문당 공헌이익 − (고정비·대표보상 확보분)
목표 ROAS = 소비자 결제액 ÷ 목표 CAC
```

→ 산출물: **양식 12 광고 실험 카드**. 광고 소재(duo_yt4, ablr_yt4)별로
`가설 / 변경요소 1개 / 고정요소 / 예산상한 / 종료일 / 비교지표=환불제외 신규고객 CAC`.
→ 규칙: 제목·썸네일·가격·타깃을 **동시에 바꾸지 않는다**. 표본 부족 시 승자 판정 금지.

### 2-3. 식품용 기구 적합성 문서 정리 (20장)
듀오박스 v4 후면에 이미 **식품용 마크·1372·한글 표시사항**이 들어간다. 매뉴얼 20장 기준으로 이를 **문서로 재확인**한다.

체크 항목 (모델·재질별로 각각):
- 제품별 재질(실리콘/PP/스테인리스 등) → 「기구 및 용기·포장」 기준·규격 시험성적서 보유 여부
- 시험성적서의 **모델명·재질이 실제 출고품과 일치**하는지 (매뉴얼 반복 경고)
- 해외 시험서(CE/FDA/중국 내수)로 국내 요건을 대체하고 있지 않은지
- 아이스볼/텀블러 등 **음용 접촉부**와 단순 몰드의 요건 차이
- 표시사항 문구가 실제 수입자·제조원과 일치하는지

→ 산출물: **양식 08 규제 확인 요청서** 1건을 관세사·시험기관에 동일 자료로 발송.
질문 형식: "이 구성·용도의 모델을 이 사업자가 판매용으로 수입할 때 필요한 요건·근거·절차·기간·비용은?"
→ 기록: `확인 기관 / 적용 요건 / 확인일 / 증빙 / 남은 조건` 5열. 모델 변경 시 재확인.

### 2-4. 13주 현금표 (23장 + 양식 10)
컬러박스 **10,000개** 발주처럼 큰 단위 지출이 있는 구조라 필수.

행 구성: 기초현금 / 고객 정산(입금 예상 주차 기준) / 공급자 계약금·잔금 / 운임·관세·수입부가세 / 광고·급여·고정비 / 환불 / 기말현금 / 최소잔액 차이
시나리오 3개: **기본 / 정산 2주 지연 / 판매량 30% 감소**

→ 판정: 어느 주에 현금이 바닥나는지 명시. 그 주 이전에 **박스·몰드 추가 발주 금지선**을 긋는다.
→ 매뉴얼 경고 그대로: 수입 부가세는 공제 대상이어도 **지급 시점에는 현금이 나간다.**

## 3. 중기 적용 (3~8주)

### 3-1. 금형·권리 소유 정리 (30장) — 쥬얼아이스 고유 위험
매뉴얼: **"금형비는 금형 소유권과 같은 말이 아니다."**
듀오메이커는 자체 몰드가 핵심 자산이므로 다음을 계약서에서 확인·보완한다.

- 금형 식별번호 / 보관 장소 / **소유권 명의** / 사용 제한(타사 생산 금지) / 유지보수 / 수명 / 손상 시 처리 / 이전·반환 / 계약 종료 시 처리
- 도면·3D 파일·시험자료 **접근권**
- 공장이 부품·재질·협력공장을 바꿀 때 **사전 서면 통지·승인** 의무
- 공급자 교체가 불가능한 구조라면 → 가격 협상력 상실분을 원가에 반영

→ 산출물: **양식 20 OEM 사양·변경 관리서** 1부 (듀오메이커 기준).

### 3-2. Abler 유통 관계를 16항목으로 점검 (27장)
Abler 라인은 자사 브랜드가 아니라 **유통 라인**이다. 계약(또는 구두 합의)을 16항목에 대입해 빈칸을 찾는다. 특히 쥬얼아이스에서 사고가 나기 쉬운 6개:

| 항목 | 확인 질문 |
|---|---|
| 2. 제품 범위 | 후속 모델·신규 컬러가 자동 포함되는가 |
| 4. 채널 | 자사몰/마켓/오프라인/B2B/본사 직판 예외 |
| 5. 독점성 | 계열사·다른 도매상 경유 공급 취급 |
| 11. 인증·현지화 | 인증 **명의**와 비용 부담, 종료 시 미회수분 |
| 13. 상표·콘텐츠 | 우리가 만든 상세페이지·영상·사진의 **재사용·이전 권리** |
| 15. 해지·재고 | 종료 시 잔여 재고 판매기간·환매·보증 승계 |

→ **13번이 특히 중요**: `ablr-zero-detail/` 25컷과 `ads/ablr_yt4_*` 는 쥬얼아이스가 제작한 자산이다.
계약 종료 시 누구 소유인지, 본사가 재사용할 수 있는지 문서화되어 있지 않으면 **지금 정리한다.**
→ 매뉴얼 28장 경고: 독점 총판 = 상표권 아님, 병행수입 일괄 차단 권리 아님. 네 가지(독점계약상 권리 / 상표권 / 콘텐츠 이용권 / 인증 권한)를 네 줄로 분리해 쓸 수 있어야 한다.

### 3-3. 상세페이지 재검수 (14장 + 양식 11)
`ablr-zero-detail/` 은 이미 25섹션 구조(문제→구조→충격테스트→용량→비교→누구에게 맞는가→**맞지 않는가**→FAQ)로 매뉴얼 권고와 거의 일치한다. **잘 되어 있는 쪽**이다. 보완 포인트만:

- 모든 **성능·보증·원산지 주장에 근거**가 붙었는가 (충격/낙하 테스트 = 사내 관찰인지 기관 시험인지 표기)
- 중요한 제약을 하단 작은 글씨에 숨기지 않았는가
- 제조사 이미지·해외 리뷰 사용 **권리 범위** 확인
- 듀오박스 v4는 "박스 겉에 사용법·시간 숫자 없음 → QR" 구조 = 매뉴얼 14장과 부합. 단 **QR 랜딩(`jewelice.kr/first-ice.html`)이 고객 질문 10개에 답하는지** 점검
- AI 생성 후기·가상 후기 사용 금지 (16장), 체험단은 공정위 추천·보증 지침 표시 준수

### 3-4. 반품·보증·클레임 SOP (18장 + 양식 14)
얼음 몰드·텀블러는 **식품 접촉 + 파손** 클레임이 동시에 나오는 품목이다.
- 클레임을 6분류로 고정: 단순변심 / 설명과 다름 / 초기불량 / 운송파손 / 사용상 문제 / 보증 중 고장
- 청약철회 7일 원칙과, **표시·광고와 다른 이행 시 3개월·30일** 별도 기준을 고지문에 반영
- 월말에 **사유별 비용 집계** → 설명 보완으로 막을 반품 / 포장 변경으로 막을 파손 / 판매중단할 결함 구분
- 고객 해결과 공급자 구상을 **별개 사건으로 관리** (공급자 회신 지연이 고객 환불 지연 사유가 되지 않게)

## 4. 조건부·장기 (9~13주 이후)

### 4-1. B2B·도매 채널 (29장)
아이스볼/듀오메이커는 **바·카페·호텔·위스키 리테일**과 고객이 겹친다. 다만 매뉴얼 경고대로 "소매가에서 %를 빼는 방식"으로 도매가를 정하지 않는다.

```
도매 공헌이익 = 도매 공급가액 − 도착원가 − (도매 배송·지원·예상보증비)
```
→ 파일럿: **매장 5곳 × 소량 입점**, 소비자 판매·반품·재주문까지 회수해야 성공 판정.
→ 매뉴얼 경고: "매장에 보낸 10개를 소비자 판매 10개로 보고하지 않는다" (Sell-in ≠ Sell-through).
→ 권장소비자가는 되지만 **재판매가 강제는 공정거래 검토 전 시행 금지**.
→ 외상은 초기 선결제·짧은 주기부터. 거래처별 채권 나이 주간 확인.

### 4-2. 포트폴리오 판단 (34장)
자사 브랜드(듀오메이커·아이스볼)와 유통 라인(Abler)이 **물류·고객·A/S·콘텐츠 제작 역량**을 공유하는 구조다. 매뉴얼 기준으로 확인할 것:
- 신규 브랜드마다 **별도 손익·현금계획**을 만든다 (잘 팔리는 라인의 현금으로 부진 라인을 무기한 떠받치지 않는다)
- 적자 라인이 유입을 만든다면 **실제로 다른 구매로 이어지는지 측정**
- 확장 전 조건: 기존 사업이 **대표자 매일 개입 없이** 유지되는가

### 4-3. AI·자동화 (33장) — Charles 강점 구간
매뉴얼 권고 순서: **읽기·분류·알림 → 그 다음 실행**.
1단계(즉시 가능): 주문 상태 지연 알림 / 증빙 누락 표시 / 재고 기준 도달 알림 / 문의 자동 분류
2단계(권한·한도·승인·감사기록 준비 후): 발주·송금·환불·가격 대량변경
금지선: 법규 판정, 인증번호 진위, 공급자 신원, 제품 성능·후기를 AI가 **추정으로 채우게 하지 않는다**.
개인정보는 주문번호·익명화 정보만 투입.

매뉴얼이 제시한 검수 프롬프트를 그대로 사내 표준으로 채택:
> "아래 견적을 동일 통화와 인도조건으로 비교하라. 제공되지 않은 비용을 0으로 두지 말고 미확인으로 표시하라. 공개 판매가격과 실제 공급 견적을 구분하라. 결론에는 확인된 사실, 가정, 추가 질문, 다음 행동을 따로 작성하라."

## 5. 중단·경보 기준 (40장) — 시작 전에 숫자로 못 박는다

다음 중 하나라도 발생하면 **신규 광고·신규 발주를 즉시 멈추고** 기존 주문·의무부터 처리한다.

1. 13주 현금표의 **최소 유지 잔액 하회**
2. 특정 SKU가 정상가에서 **2개월 연속 공헌이익 음수** (개선 실험 1회 실패 포함)
3. 식품용 기구 **필수 적합성 자료 미확보** 또는 성적서와 출고품 모델 불일치
4. 공급자의 **미승인 재질·부품·협력공장 변경** 확인
5. 반복 결함·안전 관련 사고 인지 → 판매 보류·재고 격리·영향 범위 확인·신고 의무 검토 우선

## 참고: 매뉴얼 자체의 한계 (그대로 믿으면 안 되는 부분)

매뉴얼이 스스로 밝힌 범위: 원전(비아토르 모소·익스크루시브)의 **영상·비밀번호 자료·첨부 계약서 본문은 미확보**이며, 계산 예시·평가 배점은 **편집자가 새로 작성한 가정**이다. 점수표(공급자 100점, 총판 준비도 100점)는 **검증된 예측 모델이 아니다.**
따라서 쥬얼아이스는 **양식·체크리스트·판정 기준**만 가져오고, **배점과 예시 숫자는 자사 장부로 교체**한다.
